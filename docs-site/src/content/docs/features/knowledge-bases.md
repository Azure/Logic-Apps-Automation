## Overview

:::note
Availability can vary by environment. If you can't find this capability in the [portal](https://auto.azure.com), check with your environment administrator.
:::

In Azure Logic Apps Automation, a *knowledge base* is an external context source that an [agent](/features/agents/) can use. For more information, see [Knowledge setup overview](/guides/create-knowledge-bases/).

If you encounter problems, [report a bug](/support/report-a-bug/).

## Supported source types

Current source types, limits, and permission requirements aren't documented here.
