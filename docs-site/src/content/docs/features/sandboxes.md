## Overview

:::note
This capability is in preview and subject to the [Supplemental Terms of Use for Microsoft Azure Previews](https://azure.microsoft.com/support/legal/preview-supplemental-terms/). If your environment enables this capability, the user experience appears in the [portal](https://auto.azure.com).
:::

In Azure Logic Apps Automation, a *sandbox* is an environment where [agents](/features/agents/) can run code in workflows. For setup guidance, see [Sandbox setup overview](/guides/create-sandboxes/).

## Sandbox types

The setup guide covers the [default sandbox](/guides/create-sandboxes/#use-the-default-sandbox) and [prebuilt sandbox configurations](/guides/create-sandboxes/#create-a-prebuilt-sandbox). Current availability and capabilities aren't documented here.

## Prebuilt sandbox contents

Current resource tiers, repository options, and authentication methods aren't documented here.

## Build and management lifecycle

Before rebuilding or deleting a configuration, review its current status and confirm the effects of the action.

## Files and workspace

Confirm how inputs, outputs, and repository files are made available before relying on specific paths or output formats.

## Access and ownership

Before creating, editing, rebuilding, or deleting a sandbox configuration, confirm the required access with your environment administrator. For more information, see [Permissions](/features/permissions/#sandbox-roles).
